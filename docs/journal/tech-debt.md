## Journal

| | Проблема | Почему так сейчас | Когда чинить |
|---|---|---|---|
| 🟠 | Нет ротации ключа шифрования | Для двоих — лишняя сложность | Перейти на `MultiFernet` при первой необходимости сменить ключ; до тех пор — **бэкап ключа** |
| 🟡 | Фоновый анализ на `BackgroundTasks` не переживает рестарт | Очередь (Celery/RQ) избыточна для двоих. Подстраховка: `pending` старше 5 мин отдаётся как `failed` с кнопкой «Повторить» | Если появится очередь задач в Monty |
| 🟡 | Аналитика расшифровывает все записи периода в Python | Темы зашифрованы, SQL-агрегация невозможна; при ~1000 записей это миллисекунды | Если пользователей станет много — кешировать агрегаты |
| 🟡 | Партнёр = весь `household_id`; нельзя скрыть своё настроение от партнёра | В MVP вы двое и это нужно | Флаг «показывать настроение» в настройках |
| 🟡 | Job напоминаний живёт в памяти процесса | Как и у остальных уведомлений Monty; при нескольких воркерах uvicorn задублируется | При переходе на несколько воркеров — внешний планировщик / lock |
| 🟡 | Траты в аналитике — общие по семье, не личные | Бюджет у вас общий | Переключатель «мои / общие», если понадобится |
| 🟡 | Записи только «сегодня», без бэкфилла | Защищает серию от накрутки | Разрешить правку даты без влияния на серию |
