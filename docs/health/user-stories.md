## Gym — как устроено (для пользователя)

**Одна фраза:** своя программа по дням A/B/C, свой каталог упражнений, в зале — пошаговый поход с записью каждого подхода (повторы + вес).

### Слои данных

| Что | Чья это штука | Пример |
|-----|----------------|--------|
| **Категории упражнений** | Общие для всех пользователей | Руки, Ноги, Кор, Грудь, Спина, Ягодицы (наполняем мы) |
| **Упражнения** | **Только у создавшего пользователя** | RU + EN; пользователь **сам добавляет**; другие пользователи **не видят** чужие |
| **Архив упражнения** | Личный | Убрал из активного каталога — не предлагается в программе, но **история походов** сохраняется |
| **Моя программа** | Личная | Дни **A**, **B**, **C**, … |
| **Упражнение в дне** | Личная программа | План: **подходы × повторения** |
| **Поход в зал (сессия)** | Личный факт | По каждому подходу: **повторения + вес (кг)**; упражнение можно **пропустить** — это видно в итоге и истории |

### Принятые решения (продукт)

| ID | Решение |
|----|---------|
| [D1](./decisions.md#d1-незавершённая-тренировка) | Активная сессия → модалка «Продолжить / начать новую (старая удалится)» |
| [D2](./decisions.md#d2-вес-0--без-снаряда) | Вес **0** или пусто — разрешено |
| [D3](./decisions.md#d3-повторений-больше-чем-в-плане) | Любое число повторений, без подсветки «выше плана» |
| [D4](./decisions.md#d4-архив-упражнения-которое-в-программе) | Архив → предупреждение + **убрать из планов**, история сохраняется |
| [D5](./decisions.md#d5-одна-или-несколько-программ) | **Одна** программа на MVP |

| Решение | Как для пользователя |
|---------|----------------------|
| Кто создаёт упражнения | Сам пользователь; только его каталог |
| Прошлый вес | Плейсхолдер / «Прошлый раз: X кг» при записи подхода [MVP] |
| Haptic | Старт подхода и конец отдыха (Telegram), без звука [MVP] |
| Отдых | 90 сек + **+30 / −15** на экране; без экрана настроек [MVP] |
| Завершить на «Что дальше?» | Только **⋯**, не большая кнопка [MVP] |
| Поиск, drag в программе, zero states | [MVP] — см. [decisions.md § MVP](./decisions.md#mvp-vs-бэклог) |

## Gym — настройка программы

### G-1. Создать свою программу с днями A, B, C…

**Кто:** пользователь, настраивает сплит.  
**Триггер:** первый заход в **Моя программа** или пустая программа.

| Шаг | Действие |
|-----|----------|
| 1 | Открыть **Моя программа** |
| 2 | Добавить день: буква/название (**A**, **B**, **C**, …) |
| 3 | Повторить — сколько угодно дней |
| 4 | Сохранить |

**Результат:** есть личная программа с одним или несколькими тренировочными днями.

**Исключения:**

- **Одна программа** на пользователя ([D5](./decisions.md#d5-одна-или-несколько-программ)).
- Пустая программа — zero state: «У вас пока нет программы» + **Создать первый день** (см. G-1z).
- Переименовать / удалить день — см. G-2.

---

### G-2. Изменить дни программы

**Триггер:** поменял сплит (добавил день D, убрал старый).

| Шаг | Действие |
|-----|----------|
| 1 | **Моя программа** → список дней |
| 2 | Добавить / переименовать / удалить день |
| 3 | Подтвердить при удалении, если в дне уже есть упражнения |

**Результат:** актуальный набор дней A, B, C…

**Исключения:**

- Удаление дня с упражнениями — предупреждение; история **прошлых походов** этот день не стирает.

---

### G-3. Добавить упражнение в день (план: подходы и повторения)

**Триггер:** собираю содержимое дня B.

| Шаг | Действие |
|-----|----------|
| 1 | **Моя программа** → день **B** |
| 2 | «Добавить упражнение» → выбор из **каталога** (поиск / категория) |
| 3 | Указать **число подходов** и **повторений** (план на этот день; вес задаётся в зале по факту, см. G-12) |
| 4 | Сохранить |

**Результат:** в дне B появилась строка: упражнение + план 3×10 (пример).

**Исключения:**

- То же упражнение можно добавить в день B и в день C — это разные строки программы.
- **Порядок в дне:** drag-and-drop в **Моя программа** [MVP] (в зале порядок по-прежнему гибкий — G-13).

---

### G-3d. Изменить порядок упражнений в дне (drag)

**Триггер:** хочу другой порядок в плане (не только в зале).

| Шаг | Действие |
|-----|----------|
| 1 | **Моя программа** → день |
| 2 | Перетащить строки упражнений |
| 3 | Порядок сохранён |

**Результат:** в каталоге дня новый порядок; при походе можно всё равно начать с любого (G-11, G-13).

---

### G-4. Убрать или изменить план упражнения в дне

**Триггер:** поменял схему (было 4×8, стало 3×10).

| Шаг | Действие |
|-----|----------|
| 1 | День → строка упражнения |
| 2 | Изменить подходы/повторения или удалить из дня |
| 3 | Сохранить |

**Результат:** план в программе обновлён; старые походы в **Истории** не переписываются.

## Gym — мой каталог упражнений

### G-5. Посмотреть свои упражнения по категориям

**Триггер:** ищу упражнение или смотрю свою базу.

| Шаг | Действие |
|-----|----------|
| 1 | Раздел **Упражнения** |
| 2 | Список **категорий** (общие: Руки, Ноги, Кор, …) |
| 3 | Тап по категории → **мои** активные упражнения внутри |
| 4 | В карточке: **название RU** и **название EN** |

**Результат:** нашёл упражнение для программы (G-3) или редактирования.

**Исключения:**

- В категории нет моих упражнений — «Добавьте первое» + CTA (G-6).
- **Архивные** в основном списке не показываются — см. G-7.
- Каталог пуст — zero state + **Создать упражнение**.

---

### G-5s. Поиск упражнения в каталоге

**Триггер:** много своих упражнений, ищу по названию.

| Шаг | Действие |
|-----|----------|
| 1 | **Упражнения** → поле поиска |
| 2 | Ввожу RU или EN |
| 3 | Список фильтруется |

**Результат:** нашёл без пролистывания 30+ позиций [MVP].

---

### G-6. Добавить своё упражнение

**Триггер:** в каталоге нет нужного движения.

| Шаг | Действие |
|-----|----------|
| 1 | **Упражнения** → «Новое упражнение» |
| 2 | Выбрать **категорию** |
| 3 | Ввести название **RU** и **EN** |
| 4 | Сохранить |

**Результат:** упражнение есть **только у меня**; доступно в G-3, G-5 и в походе.

**Исключения:**

- Дубликат названия у себя — *TBD: предупреждение или разрешить*.

---

### G-7. Архивировать упражнение

**Триггер:** больше не делаю это движение, но историю сохранить.

| Шаг | Действие |
|-----|----------|
| 1 | **Упражнения** → карточка упражнения |
| 2 | «В архив» |
| 3 | Если упражнение **в программе** — модалка [D4](./decisions.md#d4-архив-упражнения-которое-в-программе): удалится из планов, в истории останется |
| 4 | Подтвердить → убрать из дней программы, скрыть из активного каталога |

**Результат:** каталог не засорён; **История** не меняется.

**Исключения:**

- Раздел **«Архив»** + вернуть (G-8) — желательно в MVP.

---

### G-8. Вернуть упражнение из архива — *желательно MVP*

**Триггер:** снова включил движение в ротацию.

| Шаг | Действие |
|-----|----------|
| 1 | **Упражнения** → **Архив** |
| 2 | Тап по упражнению → «Вернуть в каталог» |

**Результат:** снова доступно в G-3 и G-5.

## Gym — поход в зал (активная тренировка)

Ядро продукта: не просто «отметил, что был», а **сессия с выбором дня, упражнений и фактом по каждому подходу**.

### G-9. Продолжить незавершённую тренировку

**Триггер:** открыл Gym, в БД есть **активная** сессия ([D1](./decisions.md#d1-незавершённая-тренировка)).

| Шаг | Действие |
|-----|----------|
| 1 | Модалка: «Найдена активная тренировка от **[дата]**» |
| 2 | **Продолжить** → вернуть на экран, где остановился (день, упражнение, подход) |
| 3 | **Начать новую** → старая сессия **удаляется** → G-10 |

**Результат:** прогресс не теряется при случайном закрытии приложения.

---

### G-10. Начать тренировку

**Триггер:** пришёл в зал, открываю Gym.

| Шаг | Действие |
|-----|----------|
| 1 | **Тренировка** → «Начать тренировку» |
| 2 | Выбор **дня программы** (A / B / C / …) |
| 3 | На экране подсказка: **«В прошлый раз был день X»** (из последней завершённой сессии) |
| 4 | Подтвердить день |

**Результат:** создана активная сессия, привязана к выбранному дню и дате.

**Исключения:**

- Нет завершённых сессий раньше — блок «в прошлый раз» не показываем или «Это ваш первый поход».
- Есть незавершённая сессия — сначала **G-9**, не G-10.

---

### G-1z. Пустое состояние программы

**Триггер:** нет ни одного дня в программе.

| Шаг | Действие |
|-----|----------|
| 1 | **Моя программа** → иллюстрация + текст «У вас пока нет программы» |
| 2 | CTA **«Создать первый день»** → G-1 |

**Результат:** понятно, с чего начать [MVP].

---

### G-11. Выбрать, с какого упражнения начать

**Триггер:** день выбран (после G-10).

| Шаг | Действие |
|-----|----------|
| 1 | Список упражнений **плана на этот день** (подходы × повторения из программы) |
| 2 | Выбрать **первое упражнение** на сегодня (порядок в зале может быть любым) |
| 3 | Перейти в экран выполнения упражнения |

**Результат:** сессия знает текущее упражнение; дальше G-12.

---

### G-12. Выполнить подходы по упражнению (по одному)

**Триггер:** иду по плану дня, делаю текущее упражнение.

Подходы идут **строго по очереди**: на экране всегда **один текущий подход**, не вся таблица сразу.

| Шаг | Действие |
|-----|----------|
| 1 | Вижу упражнение (RU/EN), **план** N×M, индикатор «подход **K** из N» |
| 2 | Статус **«Ожидание»** → **«Начать подход»** (момент старта: встал к снаряду) |
| 3 | Статус **«Подход идёт»** → **анимация гантели** + подсветка карточки; делаю в зале → **«Записать результат»** |
| 3a | В **«Ожидании»** — та же гантель **без анимации** (бледная), чтобы был контраст «ещё не начал / пошло» |
| 4 | Форма: **вес** (0 или пусто — [D2](./decisions.md#d2-вес-0--без-снаряда)) и **повторения** (любое число — [D3](./decisions.md#d3-повторений-больше-чем-в-плане)); подсказка **«Прошлый раз: X кг»**; haptic при «Начать подход» и по окончании отдыха |
| 5 | **«Сохранить»** → если есть ещё подходы: **таймер отдыха** (**90 сек**) |
| 5a | На отдыхе: отсчёт, **«Пропустить отдых»**, **+30 / −15 сек**; по нулю — снова шаг 2 (ожидание) |
| 5b | После **пропуска подхода** отдых **не** идёт — сразу шаг 2 |
| 6 | Сверху — список записанных подходов (1: 60×10, …) |
| 7 | После **последнего** подхода — **G-13** («что дальше?») |
| 8 | **«Пропустить подход»** — мелкая ссылка, не большая кнопка; **модалка «Уверены?»** |
| 9 | **Пропустить упражнение** / **Завершить тренировку** — только в меню **⋯** в шапке, с подтверждением (не на основном экране) |

**Результат:** по каждому подходу: **сделано** (вес + повторения) или **пропуск**; всё видно в списке подходов, итоге и истории.

**Исключения:**

- **«Вернуться»** на «Подход идёт» → снова «Ожидание».
- Все подходы пропущены — упражнение закрыто, в истории видны пропуски.

---

### G-13. Выбрать следующее упражнение (не только по порядку списка)

**Триггер:** закончил текущее упражнение (G-12).

| Шаг | Действие |
|-----|----------|
| 1 | Экран **«Что дальше?»** — прогресс «N/M упражнений» (желательно) |
| 2 | Список оставшихся (сделанные / пропущенные помечены) |
| 3 | Выбрать упражнение → G-12 |
| 4 | **Завершить тренировку** — только **⋯** в шапке ([MVP](./decisions.md#mvp-vs-бэклог)), не большая кнопка на экране |

**Результат:** порядок в зале гибкий; меньше случайного завершения похода.

---

### G-14. Завершить тренировку

**Триггер:** закончил в зале (все упражнения сделаны, часть пропущена, или вышел раньше).

| Шаг | Действие |
|-----|----------|
| 1 | **Завершить** — меню **⋯** (с подтверждением), в любой момент похода |
| 2 | Итог: день (B), дата; список упражнений со статусами **сделано** / **пропущено** / частично |
| 3 | Подтвердить |

**Результат:** сессия закрыта; пропуски **видны**; **«в прошлый раз был день X»** обновится (G-10).

**Исключения:**

- Ни одного подхода не записано — *TBD: разрешить завершить или предупреждение*.
- Две сессии в один календарный день — *TBD*.

## Gym — история

### G-20. Посмотреть прошлый поход

**Триггер:** вспомнить, что делал на прошлой тренировке.

| Шаг | Действие |
|-----|----------|
| 1 | **История** |
| 2 | Список сессий (дата, **день A/B/C**) |
| 3 | Тап → детали: по каждому упражнению — **сделано** / **пропущено**; по подходам — повторения и **вес** |

**Результат:** виден полный факт похода, включая пропуски.

---

### G-21. Сравнить с планом в прошлой сессии

**Триггер:** «делал ли 3×10 или меньше».

| Шаг | Действие |
|-----|----------|
| 1 | **История** → сессия → упражнение |
| 2 | Вижу план (подходы × повторения), факт (повторения + **кг**), **пропуск отдельного подхода** или всего упражнения |

**Результат:** понятно, где не добрал повторений, пропустил подход или не дошёл до упражнения.
