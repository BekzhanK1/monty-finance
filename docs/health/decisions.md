# Решения продукта — Gym (Health)

**Статус:** принято для MVP.  
Сценарии: [user-stories.md](./user-stories.md).

---

## D1. Незавершённая тренировка

**Решение:** при входе в Gym, если есть активная сессия — **модалка**.

> Найдена активная тренировка от **[дата]**.  
> **Продолжить** или **начать новую** (старая будет удалена)?

Без этого при закрытии приложения пользователь теряет прогресс — сильный негатив.

---

## D2. Вес 0 / без снаряда

**Решение:** **разрешить**. Поле веса: пусто или **0**.

Кейсы: подтягивания, отжимания, пресс.

---

## D3. Повторений больше, чем в плане

**Решение:** **разрешить**, без подсветки «выше плана». Свободный ввод числа, факт в БД.

Не тратим время на валидацию и цветовые индикаторы в MVP.

---

## D4. Архив упражнения, которое в программе

**Решение:** **предупреждение + авто-удаление из планов**.

> Это упражнение используется в программе. При архивации оно **удалится из ваших планов**, но **останется в истории**. Продолжить?

---

## D5. Одна или несколько программ

**Решение:** **строго одна программа** на MVP.

Несколько программ → сущности «активная/неактивная», усложнение старта тренировки. Отложено в V2.

---

## MVP vs бэклог

### Поход в зале — в MVP

| Фича | MVP |
|------|-----|
| Прошлый вес | Плейсхолдер или текст «Прошлый раз: X кг» |
| Haptic (Telegram) | Старт подхода, конец отдыха (без звука) |
| Отдых | **90 сек** захардкожено; на экране **+30 / −15 сек** |
| Завершить тренировку на «Что дальше?» | Только через меню **⋯**, не большая кнопка |

### Поход — V2

| Фича | Причина отложения |
|------|-------------------|
| Кнопки +2.5 / −2.5 кг | Хватит numpad |
| Настройка 60/90/120 отдыха | +30/−15 закрывает кейсы |
| Таймер длительности подхода | Шум для MVP |

### Программа, каталог, история — в MVP

| Фича | MVP |
|------|-----|
| Поиск RU/EN в каталоге | Обязательно |
| Drag-and-drop порядка в дне | Обязательно |
| Пустые состояния (zero states) | CTA «Создать» |

### Программа, история — V2

| Фича | Причина отложения |
|------|-------------------|
| Копировать день / дублировать тренировку | Редко, 1–2 мин руками |
| График веса | Долго на фронте; пока список + «в прошлый раз X» |
| Цель N походов в неделю | Нотификации, сброс счётчиков |
