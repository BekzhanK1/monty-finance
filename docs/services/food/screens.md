# Экраны и навигация

## Вход в сервис

**Все сервисы** → плитка **Food** → `/food` с умным редиректом ([D1](./decisions.md)):

| Условие | Куда |
|---------|------|
| В каталоге ≥ 3 блюд (в т.ч. после сида) | `/food/menu` |
| Иначе | `/food/catalog` + баннер онбординга «создайте 3 блюда» |

После сида (5 блюд) новый пользователь сразу попадает в **Меню**.

Общий layout: верхние вкладки (desktop) + нижняя панель (mobile), 5 разделов.

---

## 1. Каталог (`/food/catalog`)

**Цель:** база блюд и продуктов.

### Секции (вкладки или подразделы)

| Секция | Содержимое |
|--------|------------|
| Блюда | Список / сетка, поиск, фильтр по категории и тегам |
| Продукты | Справочник ингредиентов |

### Экран «Блюдо» (деталь / редактор)

- Название, категория приёма пищи
- Текст рецепта (многострочный)
- Таблица ингредиентов: продукт, кол-во, единица, опционально
- Порции по умолчанию (`servings_default`)
- Действия: сохранить, **в архив**, «Добавить в меню»

### Пустые состояния

- Нет блюд → CTA «Создать первое блюдо» + примеры (опционально сид)
- Нет ингредиентов → подсказка: появятся при заполнении состава блюд

---

## 2. Меню (`/food/menu`)

**Цель:** планирование недели.

### Основной вид

- Заголовок: диапазон дат недели (пн–вс)
- Стрелки ← → , кнопка «Сегодня»
- Сетка: строки = слоты (завтрак…ужин), столбцы = дни
- Ячейка: название блюда или «+» / «—»

### Взаимодействия

| Жест | Результат |
|------|-----------|
| Тап по ячейке | Bottom sheet: выбор блюда / текст / порции / очистить |
| Долгий тап | Фаза 2: копировать день |
| Меню «⋯» | Повторить неделю, применить шаблон |

### Индикаторы

- Сегодня — подсветка колонки
- Пустая неделя — баннер «Заполните меню»

---

## 3. Гид (`/food/guide`)

**Цель:** готовить, не редактировать.

### Основной вид

- Та же навигация по неделям
- Список по дням: день недели → слоты → название
- Тап → drawer/полноэкран: рецепт + состав

### Отличия от Меню

- Нет «+» в ячейках
- Акцент на читаемость текста рецепта
- Ссылка «Изменить» → Каталог или Меню

---

## 4. Список (`/food/shopping`)

**Цель:** покупки с правкой под реальную корзину.

### Состояния

| Состояние | UI |
|-----------|-----|
| Нет списка | CTA «Сгенерировать из меню» + «Пустой список» |
| Активный список | Позиции, **редактируемые количество/единица/цена** [F3], чекбоксы, счётчик «осталось N» |
| Завершён | Read-only или архив, кнопка «Новый» |

### Элементы экрана

- Период / название списка
- Кнопки: Сгенерировать, Добавить позицию, **«На склад»** [F4], Завершить, В Finance
- Повторная генерация: модалка «новый список» (дефолт) / «обновить черновик»
- Строка позиции: 
  - Чекбокс «куплено»
  - Название
  - **Редактируемые поля: количество, единица, цена** (сохранение onBlur)
  - Badge «единицы» при unit mismatch
- Итог суммы по ценам
- **«На склад»** — пакетная кнопка для отправки купленных позиций на склад [D13]
- Фаза 2: группировка по категории продукта

### Режим магазина (фаза 2)

Toggle «Только некупленное», увеличенный шрифт.

---

## 5. Склад (`/food/pantry`)

**Цель:** остатки дома.

### Основной вид

- Список: продукт, количество, место, срок (если есть)
- FAB / кнопка «Добавить»
- Поиск и фильтр по месту хранения

### Форма позиции

- Выбор продукта (autocomplete)
- Количество + единица
- Место, дата годности

---

## 6. Глобальные UI-паттерны

| Паттерн | Применение |
|---------|------------|
| Bottom sheet | Выбор блюда в меню, быстрые действия |
| Drawer | Деталь рецепта в Гиде |
| Toast | Сохранено, ошибка сети |
| Haptic | Telegram Mini App при переключении вкладок |
| Loading | Скелетоны на недельной сетке |

Визуальный стиль — общий с Finance (Mantine, violet/grape акценты).

---

## 7. Экраны вне вкладок (будущее)

| Экран | Когда |
|-------|-------|
| Настройки Food | отдельный пункт в Settings Monty |
| Шаблоны недели | модалка из Меню |
| AI-черновик меню | модалка / отдельный wizard |
| Архив списков | из Список → «История» |

## 8. Соответствие «экран ↔ API» (для разработки позже)

| Экран | Основные операции |
|-------|-------------------|
| Каталог | CRUD блюд, ингредиентов, категорий |
| Меню | CRUD слотов, query по датам |
| Гид | read-only те же слоты + блюда |
| Список | generate, CRUD позиций, finalize |
| Склад | CRUD pantry |

Детальный контракт — в legacy [`food-data-model-v2.md`](../../food-data-model-v2.md).
