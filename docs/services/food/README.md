# Сервис «Еда» (Food)

Продуктовая спецификация Monty Food — **без кода**, для согласования «что строим» до и параллельно с разработкой.

## Для кого

Одна пара / один дом: **общее меню, общий каталог, один список покупок**. Два Telegram-аккаунта — два клиента к одним данным. Роли и «мои/твои» блюда не нужны.

## Зачем сервис в Monty

Ответ на вопрос: **«Что готовим дома на этой неделе и что купить?»** — без хаоса в заметках и чатах. В перспективе — связка с **Finance** (сколько тратим на продукты) и задел под **Health** (питание).
