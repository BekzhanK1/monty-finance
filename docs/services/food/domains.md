# Функциональные домены

Ниже — **полная карта возможностей** сервиса «Еда». Для каждого блока: сущности, действия, правила. Реализация по фазам — в [roadmap.md](./roadmap.md).

---

## 1. Каталог блюд и продуктов

### 1.1 Блюда (рецепты)

**Сущность:** блюдо — то, что вы реально готовите дома.

| Поле / аспект | Обязательность | Заметки |
|---------------|----------------|---------|
| Название | да | |
| Категория приёма пищи | да | Завтрак / Обед / Ужин / Перекус (настраиваемый список) |
| Текст рецепта | нет | Свободная форма: шаги, ссылка, «как у мамы» |
| Структурированные ингредиенты | нет | Продукт + количество + единица |
| Порции по умолчанию | нет | Для масштабирования в меню |
| Время prep/cook | нет | Для фильтров «быстро» |
| Теги | нет | vegan, batch, детям, праздник |
| Фото | нет | URL или загрузка позже |
| Архив (`is_archived`) | да | Скрыть из выбора; прошлые слоты меню сохраняют название |

**Действия:** создать, редактировать, дублировать, **архивировать** (вместо жёсткого удаления, если блюдо было в меню).

**Правила:**

- Блюдо без ингредиентов всё равно можно ставить в меню.
- Дублирование блюда копирует состав и текст.

### 1.2 Справочник продуктов (ингредиенты)

**Сущность:** нормализованный продукт («лук репчатый», «гречка»).

| Аспект | Заметки |
|--------|---------|
| Название | Уникальность в рамках дома (мягкая: подсказка «уже есть») |
| Категория продукта | овощи, мясо, бакалея… — для группировки в списке |
| Единица по умолчанию | г / мл / шт |
| `is_pantry_default` | соль, масло, специи — не попадают в список при генерации |

**Действия:** поиск, создать при вводе, объединить дубликаты (фаза 2).

### 1.3 Единицы измерения

Справочник: `г`, `кг`, `мл`, `л`, `шт`, `ст.л.`, `ч.л.`, `стакан`…

**Правила (фаза 2+):** конвертация в базовую единицу для суммирования; на MVP — суммируем только одинаковые `(продукт, единица)`.

### 1.4 Теги блюд

Цветные метки для фильтрации каталога и будущего AI-меню.

## 2. Планирование меню

### 2.1 Слоты меню

**Сущность:** одна ячейка = **дата** + **слот** (завтрак / обед / ужин / перекус).

| Содержимое слота | Варианты |
|------------------|----------|
| Блюдо из каталога | основной сценарий |
| Свободный текст | «пицца с друзьями», «остатки» |
| Порции (`servings`) | множитель к ингредиентам: `slot.servings / dish.servings_default` |
| Заметка | «разморозить утром» |

**Действия:** назначить, сменить, очистить, копировать день, копировать неделю.

**Правила:**

- На одну дату+слот — одна активная запись (при дубликате — побеждает последняя).
- Пустой слот = «не запланировано», не «голодание».

### 2.2 Календарные представления

| Вид | Назначение |
|-----|------------|
| Неделя (сетка) | Основной экран планирования |
| День (деталь) | Быстро править один день |
| Месяц (обзор) | Фаза 2 — точки «заполнено / пусто» |

Навигация: предыдущая / следующая неделя, «сегодня».

### 2.3 Шаблоны недели (фаза 2)

**Сущность:** именованный набор слотов по дням недели (без дат).

**Действия:** сохранить текущую неделю как шаблон, применить шаблон на выбранную неделю (с подтверждением перезаписи).

Примеры: «Рабочая», «Лёгкая», «Гости».

### 2.4 Повтор и история

| Функция | Описание |
|---------|----------|
| Повторить прошлую неделю | Копировать слоты на текущую с подтверждением |
| Недавние блюда | Быстрый выбор из последних N назначений |
| Избранные блюда | Закрепить в каталоге |

## 3. Гид по готовке (поваренная книга недели)

**Назначение:** не планировать, а **готовить** — компактный вид «что и как» на выбранную неделю.

| Элемент | Поведение |
|---------|-----------|
| Список дней | Все слоты с названиями блюд |
| Карточка блюда | Текст рецепта + структурированный состав |
| Переход в каталог | Редактировать рецепт |
| Печать / share | Фаза 3 — PDF или сообщение в Telegram |

Отличие от **Меню:** Меню — редактирование слотов; Гид — read-only поток для кухни.

## 4. Список покупок

### 4.1 Списки

**Сущность:** список на период или произвольный.

| Поле | Заметки |
|------|---------|
| Название | Авто: «Покупки 12.05 — 18.05» |
| Период from–to | Связь с меню |
| Статус | черновик / активный / завершён |

### 4.2 Позиции

| Источник | Описание |
|----------|----------|
| Из меню | Агрегат ингредиентов блюд за период |
| Вручную | «Хлеб», «батарейки» — без привязки к рецепту |
| Из кладовой | «докупить» при низком остатке (фаза 2) |

| Поле позиции | Заметки |
|--------------|---------|
| Название | Из справочника или свободный текст |
| Количество + единица | |
| Галочка «куплено» | |
| Фактическая цена (`actual_price`) | Опционально; валюта — из Finance (одна на дом) |
| Группировка | По категории продукта или отделу магазина (фаза 2) |

### 4.3 Генерация из меню

**Вход:** диапазон дат (обычно текущая неделя).

**Логика:**

1. Собрать все слоты с `dish_id`.
2. Для каждого блюда: ингредиенты × `slot.servings / dish.servings_default`.
3. Суммировать только одинаковые `(ingredient_id, unit_id)`; иначе — отдельные строки.
4. Исключить ингредиенты с `is_pantry_default` (если в составе блюда не `is_optional`).
5. Вычесть кладовую (фаза 2): `нужно − есть` → в список.
6. При повторной генерации — **диалог**: новый список (дефолт) или обновить черновик `draft`.

**Действия:** сгенерировать, перегенерировать (диалог), добавить позицию, изменить количество, отметить купленным, завершить список.

### 4.4 Режим «в магазине»

- Крупный шрифт, только некупленное.
- Сортировка: по категории или как ввели.
- Офлайн не обязателен на MVP.

## 5. Кладовая (склад дома)

**Сущность:** что есть дома сейчас.

| Поле | Заметки |
|------|---------|
| Продукт | Из справочника |
| Количество + единица | |
| Место | холодильник / морозилка / полка |
| Срок годности | Опционально, напоминание (фаза 3) |

**Действия:** внести остаток, скорректировать после готовки, списать «закончилось».

**Связь со списком покупок:**

- При генерации: `нужно − есть = в список` (если `нужно > есть`).
- Быстрая кнопка «добавить в кладовую» после покупки (фаза 2).

## 6. Готовка и обратная связь (фаза 3)

| Сущность | Зачем |
|----------|-------|
| Журнал готовки | Отметить «приготовили» по слоту — аналитика «что реально ели» |
| Оценка блюда | 1–5 звёзд, комментарий — улучшать каталог |
| «Не понравилось» | Скрыть из быстрых предложений |

Не блокирует MVP.

## 8. AI и умные подсказки (фаза 3+)

Все опциональны, с явным согласием на отправку данных в модель.

| Сценарий | Вход | Выход |
|----------|------|-------|
| Предложить неделю | теги, время, бюджет, кладовая | черновик слотов |
| «Что из остатков» | кладовая | 3–5 блюд из каталога |
| Парсинг рецепта | текст / URL | черновик ингредиентов |
| Оценка стоимости | меню + средние цены | сумма на неделю (грубо) |

AI **не заменяет** ручное подтверждение перед записью в меню.

## 9. Настройки сервиса Food

| Настройка | По умолчанию |
|-----------|--------------|
| Слоты дня | завтрак, обед, ужин |
| Первый день недели | понедельник (ISO) |
| Категории приёма пищи | сид: Завтрак, Обед, Ужин, Перекус |
| Сид блюд (новый дом) | 5 блюд без ингредиентов + подсказка заполнить состав |
| Напоминания Telegram | вкл, вечер |
| Валюта для цен в списке | как в Finance |

Глобальные настройки приложения (тема, язык) — на уровне Monty, не Food.

## 10. Сводная матрица «домен → ценность»

| Домен | Без него | С ним |
|-------|----------|-------|
| Каталог | Меню из случайных названий | Повторяемые «наши» блюда |
| Меню | Хаос «на сегодня» | Неделя согласована |
| Список | Забытые продукты | Список = план |
| Кладовая | Перепокупка | Меньше лишнего |
| Гид | Копаться в чатах | Рецепт под рукой |
| Finance-мост | Ручной ввод трат | Одна кнопка «оформить покупку» |
