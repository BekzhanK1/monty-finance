# Monty 2.0 — план редизайна

Живой документ: полный редизайн Mini App, голосовой ввод внутри приложения, расширенная аналитика и новые фичи.
Статус этапов отмечается чекбоксами.

## 0. Исходное состояние

- Стиль захардкожен в `src/theme/dashboardChrome.ts` и страницах (градиенты, glass), не использует `Telegram.WebApp.themeParams`.
- Страницы-монолиты: `FoodCatalogPage` (~800 строк), `AnalyticsPage` (~620), логика + запросы + разметка вместе.
- `Transaction` не хранит источник (manual / voice / siri / bot), исходный текст, теги.
- Схема БД — `create_all` + ручные `db_bootstrap.py`; Alembic в зависимостях, но не используется.
- Демо-файлы в `components/` (`ThemeExample`, `ThemeTest`, `*.example.tsx`), тесты без раннера.

## 2. Голосовой ввод

```
🎤 удержание → MediaRecorder (webm/mp4) → POST /voice/parse
   → транскрипция (OpenAI gpt-4o-mini-transcribe)
   → общий expense_parser → черновики транзакций
   → экран подтверждения → POST /transactions/bulk
```

## 4. Advanced аналитика

| Блок | Суть |
|---|---|
| Прогноз периода | burn rate → «уложитесь / превысите на N ₸», по категориям |
| Safe-to-spend | (бюджет − потрачено) / оставшиеся дни |
| 50/30/20 | факт BASE/COMFORT/SAVINGS vs цель |
| Тренды | расходы, доходы, savings rate за 6–12 мес., скользящее среднее |
| Heatmap | календарь трат, распределение по дням недели |
| Аномалии | траты > p90 категории, всплески относительно среднего |
| Регулярные платежи | автодетект подписок, календарь списаний |
| Кто сколько | разбивка по членам семьи |
| Еда ↔ деньги | связка с Food (`finance_bridge.py`) |
| Сравнение периодов | любые два периода |
| AI-сводка | 3–4 инсайта в неделю, на главной и в дайджесте |

Фронт: drill-down группа → категория → транзакции, экспорт CSV/XLSX.

## 5. Доп. фичи

1. Цели-копилки с прогнозом даты достижения.
2. Регулярные платежи: напоминание, «оплачено» в один тап.
3. Умные уведомления: 80% бюджета категории, забытые траты.
4. Скан чека (фото/QR) → транзакции + пополнение кладовой Food.
5. Чат с финансами («сколько ушло на такси в сентябре?»).
6. Мультисчета и валюты, переводы.
7. Импорт выписки Kaspi/Halyk.
8. Офлайн-очередь.
9. Siri-шорткаты для доходов и «сколько осталось».
